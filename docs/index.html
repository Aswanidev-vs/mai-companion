Capabilities

Everything your codebase needs

Issue Review

Analyzes new issues, summarizes the problem, suggests next steps and relevant labels automatically.

PR Reviews

Reads changed files, checks diffs against best practices, and posts actionable review comments.

Mention Responses

Tag @mai-companion in any comment and get a thoughtful, grounded reply.

Live Web Search

Grounds responses in real documentation and latest library versions via Google Search.

Signature Verification

Every webhook verified with HMAC-SHA256. No spoofed requests get through.

Edge Deployed

Runs on Cloudflare Workers. Sub-50ms cold starts, no servers, scales to zero.

Setup

Running in 60 seconds

01

Deploy the worker

Clone the repo and deploy to Cloudflare Workers with a single command.

$ wrangler deploy
02

Set your secrets

API keys and credentials encrypted at the edge. Never hardcoded.

$ wrangler secret put GEMINI_API_KEY
03

Install on GitHub

Create the GitHub App, point the webhook, install on your repo. Done.
